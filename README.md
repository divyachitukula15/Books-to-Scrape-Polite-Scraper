# The Polite Scraper

## Target Classification

### Target
Books to Scrape

### Why this target
Books to Scrape is a public practice sandbox designed for learning and practising web scraping.

### Scope
Only the first 3 catalogue pages will be processed.

### Data collected
For each book, the scraper will collect:
- title
- product URL
- price
- availability
- rating
- description
- source page
- fetched timestamp

### Why this is appropriate
This target is appropriate because it is specifically provided as a practice sandbox for scraping.
